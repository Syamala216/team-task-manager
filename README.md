 Team Task Manager (Django Full Stack Project)

A professional Team Task Management Web Application built using Django. This project is designed to simulate real-world workplace task tracking systems used in IT companies for managing teams, projects, and productivity efficiently.

---

 Project Objective

The main goal of this project is to replace traditional manual task tracking (Excel/WhatsApp-based) with a centralized digital system where teams can collaborate, assign tasks, and monitor progress in real time.

---

Key Features

-  User Authentication (Login / Logout)
-  Workspace Management (Create multiple workspaces for teams/projects)
-  Task Creation & Assignment
-  Task Status Tracking (Pending / In Progress / Completed)
-  Dashboard for overall project overview
-  Team-based task organization
-  Secure user session handling

---

Real-World Use Case

This system works like a mini Jira / Trello-like tool where:
- Team leads assign tasks to members
- Developers update task status
- Admin monitors progress in dashboard
- Helps improve productivity and organization in teams

---

Tech Stack

- Backend:** Django (Python)
- Frontend:** HTML, CSS
- Database:** SQLite3
- Version Control:** Git & GitHub
- Deployment:** Railway

---

## 📂 Project Architecture

teammanage_flow/
│
├── config/          → Project settings (Django core config)
├── core/            → Main app (models, views, URLs)
├── dummy/           → Additional app module
├── templates/       → HTML templates
├── static/          → CSS & static assets
├── staticfiles/     → Collected static files
├── db.sqlite3       → Database file
├── manage.py        → Django management file
├── requirements.txt → Dependencies
├── Procfile         → Deployment config

---

 Deployment Details

- Hosted on **Railway App**
- GitHub integrated CI/CD
- Static files managed using `collectstatic`
- Production server: **Gunicorn**
- Static handling: **WhiteNoise**
- Auto deployment enabled on GitHub push
